### 🔹 Dynamisme supplémentaire

1. **Afficher le nom de l’utilisateur connecté sur HomePage** :


2. **HomePage avec BottomNavigationBar**

   * Index 0 : Accueil/Calendrier
   * Index 1 : Ajouter un RDV
   * Index 2 : Liste des RDV
   * Changement d’onglet = mise à jour dynamique du corps (`body`) au lieu de `Navigator.pushNamed`.

```dart
int _selectedIndex = 0;

Widget build(BuildContext context) {
  final pages = [CalendarPage(), AddRdvPage(), ListRdvPage()];
  
  return Scaffold(
    body: pages[_selectedIndex],
    bottomNavigationBar: BottomNavigationBar(
      currentIndex: _selectedIndex,
      onTap: (index) => setState(() => _selectedIndex = index),
      items: const [
        BottomNavigationBarItem(icon: Icon(Icons.home), label: "Accueil"),
        BottomNavigationBarItem(icon: Icon(Icons.add), label: "Ajouter"),
        BottomNavigationBarItem(icon: Icon(Icons.list), label: "Rendez-vous"),
      ],
    ),
  );
}
```

✅ Avantages :

* Pas de navigation répétitive → fluidité
* Toutes les pages accessibles via un seul scaffold
* Synchronisation Firebase déjà implémentée via `StreamBuilder`
